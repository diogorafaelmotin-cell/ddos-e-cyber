# DDOS-E-CYBER - Cyber Defense Lab 🛡️

Projeto educacional focado em **defesa** contra ataques cibernéticos, criado para fins de estudo.

🔒 Site oficial com HTTPS: https://diogorafaelmotin-cell.github.io/ddos-e-cyber/

### O que você encontra aqui:
- Conceitos de DDoS (Distributed Denial of Service)
- Técnicas de defesa: CDN, WAF, HTTPS, Rate Limiting, Firewall
- Quiz interativo sobre segurança
- Lab educacional com login demo (sem coleta de dados)

### Objetivo
Este projeto é 100% educacional e defensivo. Não contém ferramentas de ataque, apenas estudos sobre como se proteger.

### Tecnologias
- HTML5 / CSS3 (theme.css)
- GitHub Pages com HTTPS enforced

> Desenvolvido para fins de aprendizado em Curitiba, PR.
