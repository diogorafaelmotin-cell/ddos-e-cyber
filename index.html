DDOS-E-CYBER

Projeto educacional sobre defesa cibernética

O que é DDoS?

Ataque que tenta derrubar um serviço com excesso de requisições. Objetivo deste projeto: entender e se defender.

Como se Defender

  • ✅ Usar CDN e WAF (Cloudflare, etc)
  • ✅ Ativar HTTPS e Rate Limit
  • ✅ Monitorar tráfego
  • ✅ Firewall configurado
🔒 Protegido com HTTPS via GitHub Pages
